# ApiFuck 0.1.0

[English](https://github.com/tyuan511/apifuck/blob/v0.1.0/docs/release/0.1.0.md) | **简体中文**

本版将 v0.0.8 的 Tauri/React 应用替换为使用 Rust + GPUI Kit 构建的原生桌面工作台。

## 原生桌面工作台

- 使用便于 Git 管理的 OpenCollection YAML 管理集合、目录、环境和请求。编辑保留注释及未修改的格式，本地草稿可恢复未完成的工作。
- 支持多标签页、HTTP、GraphQL、WebSocket 和 SSE，变量、认证、请求脚本及测试断言共用 Rust 核心。
- 提供内置编辑器、响应视图、英文和简体中文界面，以及明暗主题；操作反馈统一使用 toast 通知。
- 通过 `cargo demo` 同时启动预填的本地 Playground API 和桌面客户端。
- JavaScript 资源内嵌于应用，下载的构建不需要 Node.js 或 Bun。
- 查看 HTTP 各次重定向和 WebSocket 握手实际发送的请求头，并结合响应详情与测试结果排查问题。
- 支持连同内容复制目录、从目录菜单新建文档，以及直接复制生成的请求代码。标签关闭后，集合和环境侧栏仍保留未保存标记。
- 代理设置可选择无代理、系统代理或自定义 HTTP/HTTPS/SOCKS5/SOCKS5H 代理；代理模式和未完成输入可随草稿恢复。

## 原生 MCP 集成

- 在设置中启用内置 MCP 服务，复制 Claude Code、Codex、OpenCode 或 Pi 的连接教程。
- Agent 可通过共用 Rust 核心管理项目和 OpenCollection 文档、选择环境、执行 HTTP/GraphQL/SSE/WebSocket 请求、运行集合，以及导入导出请求。
- 服务默认关闭，仅监听回环地址并要求令牌认证；写入操作保护未保存草稿并拒绝外部修改冲突。连接期间需保持桌面应用运行。

## macOS 应用包与安装

- 打开已签名、公证的 DMG，将 `ApiFuck.app` 拖入 Applications。应用包含图标和版本信息，应用包和 DMG 均装订公证票据。
- 应用包安装通过独立 Rust 库 `self_update` 从 DMG 更新完整应用，保留现有下载进度、草稿保存和重启流程。替换前校验新包与当前签名身份、应用 ID 和已确认版本一致。
- 下载仅提供 macOS DMG、Windows EXE 和 Linux AppImage，另附校验文件；Linux 更新替换并重启外部 AppImage 文件。
- 本次替换此前的 v0.1.0 发布。已安装 v0.1.0 的用户需手动下载，因为更新器只提供更高版本。

## 稳定性与发布工具

- 复制或移动目录时统一使用跨平台路径格式保存草稿和目录折叠状态，修复 Windows 路径分隔符导致的状态查找失败。
- 将 Bru 转换隔离到更大栈的工作线程，调整 Windows 的 QuickJS 栈限制和开发构建优化；Runner 测试使用跨平台路径比较。
- GitHub Actions 升级到 Node.js 24 运行时，消除 CI 和发布任务中的 Node.js 20 弃用警告。
- 提供英文及简体中文 README 和发布说明，下载链接更新工具保留两种语言。
- 发布等待校验和三平台构建全部成功。macOS 分发经过 Developer ID 签名和 Apple 公证，提供 DMG 及校验文件。
- 原生正式构建可静默检查 GitHub Releases，显示版本说明及下载进度，并在重启安装前保存草稿；设置中可关闭自动检查。
- 安装前校验更新附件的平台、版本、大小和 SHA-256。

## 兼容性与限制

- 从旧 Tauri 版首次升级需要手动下载；新的自动更新流程用于后续原生版本之间的升级。
- 旧 JSON 项目没有自动迁移层。请保留旧项目备份，本版使用 OpenCollection YAML。
- 目标平台为 macOS Apple Silicon、Linux x86_64 和 Windows x86_64。macOS 提供 DMG，Windows 提供 EXE，Linux 提供 AppImage。Linux 基于 Ubuntu 24.04 构建，不保证兼容更旧的 glibc 系统。
- 尚未实现 gRPC、OAuth/AWS/Digest 等高级认证及 Node 风格异步脚本；配置可导入不代表支持执行。WebSocket 不支持代理或跳过 TLS 证书校验。
- 自动化测试和构建不代表原生界面视觉验收或各 Agent 客户端的端到端联调通过，这些检查仍需人工完成。
