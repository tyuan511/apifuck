# ApiFuck 0.1.2

[English](https://github.com/tyuan511/apifuck/blob/v0.1.2/docs/release/0.1.2.md) | **简体中文**

本次 patch 基于 v0.1.1，改进脚本运行库、MCP 结果保留策略和桌面导航，并更新双语官网。

## 桌面与请求执行

- 内嵌 Chai/AJV 运行库复用只读字节码，避免每段脚本重复解析。每个 Hook 仍创建独立 QuickJS VM 和上下文，保留 2 秒、32 MiB 限制；用户全局变量和运行库修改不会跨 Hook 泄漏。
- MCP 缓存达到 32 个任务时，按完成时间淘汰最早结束的任务，不再按随机任务 ID 选择。运行中的任务不会被淘汰，成功、失败和取消的任务一致释放容量。
- 最近项目菜单新增“清除”，保存清空后的记录，不删除项目文件，也不关闭当前项目。
- 集合树滚动条贴合侧栏边缘，保留列表行的左右留白。

## 下载与官网

- 发布文件参考 electron-builder 平台命名规则并带版本号：`ApiFuck-0.1.2-arm64.dmg`、`ApiFuck-0.1.2.exe`、`ApiFuck-0.1.2.AppImage`，另附 `SHA256SUMS`。Windows 仍为便携可执行程序。
- 发布校验、校验文件、Actions 中间产物、官网下载链接和更新器同步使用匹配版本的文件名；新客户端及官网兼容识别已发布原生版本的旧文件名。
- 中英文官网新增极光首屏、特点轮换描述、响应式功能区及协议/MCP 交互示意。动画支持暂停、减少动态效果、离屏停帧和 WebGL 回退；关闭 JavaScript 后仍能阅读核心内容。

## 兼容性与验证边界

- **已安装 v0.1.0/v0.1.1 的用户需手动下载本次版本一次**：旧客户端只识别旧文件名。本版更新器可继续使用新的命名规则升级后续版本。
- 发布格式仍为 macOS Apple Silicon DMG、Windows x86_64 EXE 和 Linux x86_64 AppImage。Linux 基于 Ubuntu 24.04 构建，不保证兼容更旧的 glibc 系统。
- 自动化检查覆盖脚本、MCP 并发、更新元数据、打包和浏览器行为，不代表 GPUI 视觉验收、首次启动验收或真实安装后的更新重启流程已通过。
