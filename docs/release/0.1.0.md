# ApiFuck 0.1.0

## 原生桌面工作台

- 桌面界面从 Tauri/React 迁移到 Rust + GPUI Kit，请求执行与存储共用 Rust 核心。
- 使用 OpenCollection YAML 管理项目，支持集合、目录、环境、多标签页以及本地草稿恢复；编辑时保留 YAML 注释和未修改的格式。
- 提供 HTTP、GraphQL、WebSocket、SSE 调试，以及变量、认证、请求脚本和测试断言。
- 增加预填的本地 Playground，通过 `cargo demo` 一次启动测试 API 和客户端。
- 操作反馈统一使用 toast，保存等操作不再添加占据页面空间的通知条。

## 发布与更新

- 版本 tag 触发三平台检查和构建，通过后发布原生二进制及校验文件。macOS 在 CI 中执行 Developer ID 签名和 Apple 公证，另提供 ZIP 下载。
- 正式构建可静默检查 GitHub Releases；设置中可关闭自动检查。
- 更新面板显示版本说明和下载进度；下载后可稍后安装，点击“重启并安装”前先保存草稿。
- 更新附件按平台、版本、大小和 SHA-256 校验，失败时保留当前程序。

## 兼容性说明

- 从旧 Tauri 版首次升级需要手动下载原生版；原生版之间可使用新的自动更新流程。
- 旧 Tauri 版 JSON 项目没有自动迁移层，请先保留旧项目备份；本版使用 OpenCollection YAML。
- 发布目标为 macOS Apple Silicon、Linux x86_64、Windows x86_64，附件是独立可执行文件（macOS 另提供签名、公证后的 ZIP）；当前不包含 `.app` 或安装器。
