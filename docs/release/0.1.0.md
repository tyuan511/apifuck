# ApiFuck 0.1.0

**English** | [简体中文](https://github.com/tyuan511/apifuck/blob/v0.1.0/docs/release/0.1.0_zh-CN.md)

This release replaces the Tauri/React application from v0.0.8 with a native Rust desktop workbench built with GPUI Kit.

## Native desktop workbench

- Manage collections, folders, environments and requests in Git-friendly OpenCollection YAML. Edits preserve comments and untouched formatting; local drafts recover unfinished work.
- Work with multiple tabs, HTTP, GraphQL, WebSocket and SSE, including variables, authentication, request scripts and test assertions backed by the shared Rust core.
- Use the built-in editors, response views, English and Simplified Chinese interface, and light/dark themes. Operation feedback uses toast notifications.
- Launch the preconfigured local Playground API and desktop together with `cargo demo`.
- Embedded JavaScript resources ship inside the application. Downloaded builds do not require Node.js or Bun.
- Inspect the headers actually sent for HTTP redirects and WebSocket handshakes, alongside response details and test results.
- Duplicate folders with their contents, create documents from folder menus, and copy generated request code directly. Unsaved indicators remain visible in collection and environment sidebars even after tabs close.
- Choose no proxy, system proxy, or a custom HTTP/HTTPS/SOCKS5/SOCKS5H proxy. Proxy settings and unfinished input survive draft recovery.

## Native MCP integration

- Enable the built-in MCP service in Settings and copy connection instructions for Claude Code, Codex, OpenCode, or Pi.
- Agents can manage projects and OpenCollection documents, select environments, execute HTTP/GraphQL/SSE/WebSocket requests, run collections, and import/export requests through the shared Rust core.
- The service is off by default, binds only to loopback, and requires token authentication. Writes protect unsaved drafts and reject external-edit conflicts. Keep the desktop application running while connected.

## Reliability and release tooling

- Isolate Bru conversion on a larger worker stack and adjust QuickJS stack limits and development-build optimization for Windows. Runner tests compare paths portably.
- Update GitHub Actions to Node.js 24 runtimes, removing Node.js 20 deprecation warnings from CI and release jobs.
- Provide English and Simplified Chinese README files and release notes; the download-link helper preserves both languages.
- Release publication waits for validation and all three platform builds. macOS distribution includes Developer ID signing and Apple notarization, with a ZIP download and checksums.
- Native release builds can check GitHub Releases quietly, display release notes and download progress, and save drafts before restarting to install. Automatic checks can be disabled in Settings.
- Updates validate the platform, version, file size and SHA-256 before installation.

## Compatibility and limitations

- Upgrading from the old Tauri application requires a manual download. The new automatic updater is for subsequent native releases.
- Legacy JSON projects have no automatic migration layer. Keep a backup of old projects; this release uses OpenCollection YAML.
- Targets are macOS Apple Silicon, Linux x86_64 and Windows x86_64. Assets are standalone executables, plus the macOS ZIP; no `.app` bundle or installer is included.
- gRPC, advanced authentication such as OAuth/AWS/Digest, and asynchronous Node-style scripting are not implemented. Importing a configuration does not imply execution support. WebSocket does not support proxies or bypassing TLS certificate validation.
- Automated tests and builds do not establish native visual acceptance or end-to-end integration with each agent client; those checks remain manual.
