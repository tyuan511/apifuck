# ApiFuck 0.1.2

**English** | [简体中文](https://github.com/tyuan511/apifuck/blob/v0.1.2/docs/release/0.1.2_zh-CN.md)

This patch builds on v0.1.1 with script-runtime improvements, more predictable MCP result retention, desktop navigation refinements and a refreshed bilingual website.

## Desktop and execution

- Reuse immutable bytecode for the embedded Chai/AJV runtime instead of parsing the libraries for every script. Each hook still gets a fresh QuickJS VM and context, with the existing two-second and 32 MiB limits; user globals and library mutations do not leak between hooks.
- When the 32-job MCP cache fills, evict the earliest completed job instead of choosing by random job ID. Running jobs remain protected, and successful, failed and cancelled jobs release capacity consistently.
- Add a Clear action to the recent-projects menu. It saves the cleared history without deleting project files or closing the current project.
- Align the collection-tree scrollbar with the sidebar edge while retaining row padding.

## Downloads and website

- Versioned release filenames follow electron-builder-style platform conventions: `ApiFuck-0.1.2-arm64.dmg`, `ApiFuck-0.1.2.exe` and `ApiFuck-0.1.2.AppImage`, plus `SHA256SUMS`. Windows remains a portable executable.
- Release validation, checksums, Actions artifacts, website download links and the updater use the matching versioned names. New clients and the website also recognize previously published native filenames.
- Refresh the Chinese and English website with an aurora hero, rotating feature descriptions, responsive feature sections and interactive protocol/MCP illustrations. Animation supports pause, reduced motion, offscreen suspension and WebGL fallback; core page content remains readable without JavaScript.

## Compatibility and verification limits

- **Existing v0.1.0/v0.1.1 clients need to download this release manually once:** their updater only recognizes the old filenames. Subsequent releases can use the new naming through this client's updater.
- Formats remain macOS Apple Silicon DMG, Windows x86_64 EXE and Linux x86_64 AppImage. Linux builds target Ubuntu 24.04 and do not guarantee compatibility with older glibc systems.
- Automated checks cover scripts, MCP concurrency, update metadata, packaging and browser behavior. They do not establish GPUI visual acceptance, first-launch acceptance or a live installed-app update/restart cycle.
