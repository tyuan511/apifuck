# 工作区布局与交互

当前界面使用 GPUI Kit 原生组件，信息层级参考 Postman，API 工作流和部分数据互操作参考 Bruno。品牌资源使用 `assets/apifuck.png`，颜色与图标由应用主题统一管理。本页记录当前实现及待人工验收的行为，文件名保留以兼容已有链接。

## 导航和项目入口

- 顶部显示 logo、项目选择和启用环境；项目菜单包含“打开项目”“最近打开”“新建项目”“导入 .bru”。“最近打开”最多记录 10 个去重路径，并显示项目名称和路径。
- 集合级配置通过集合标题旁的设置按钮打开。项目菜单没有“项目设置”或“删除项目”。左侧“设置”负责应用偏好。
- 左侧功能栏切换集合、环境和设置。集合与环境各有独立搜索，新建/刷新按钮在各自标题行。
- 集合树使用固定方法列、可展开的文件夹、长名称省略和悬停说明；同级请求和目录支持拖拽排序。目录箭头控制展开，点击目录行打开配置。
- 环境列表区分“正在编辑”和“当前启用”。点击列表项只打开环境文档，启用环境由顶部选择器控制。

## 文档和标签

新建 HTTP、GraphQL、WebSocket 请求直接创建唯一文件并打开标签，名称输入自动聚焦；无需输入路径。URL 默认为空，HTTP 默认 GET，GraphQL 默认 POST。目录与环境输入显示名称后创建，实际文件路径由应用生成。名称与文件身份规则见 [存储说明](storage.md)。

文档标签支持拖动排序、横向滚动、长标题省略、完整标题列表，以及右键关闭当前/其他/左侧/右侧/全部。关闭后台标签保持当前请求，关闭当前标签选择相邻项。批量关闭同样保留草稿。

切换标签、关闭后选择相邻标签和启动恢复都会同步侧栏：请求/目录定位集合树并展开父级，环境文档定位环境列表但不改变启用环境。若搜索隐藏目标，只清除对应侧栏的搜索条件。

## 请求与响应

默认请求在上、响应在下，可切换左右布局并调整分栏。顶部方法/URL 组合输入框与发送、保存操作保持在请求区上方；运行期间发送按钮切换为停止。

请求按用途提供 Query/Path、Body、Headers、Auth、Vars、Script、Assert、Tests、Docs、Settings 和 Source 等分区。表单负责结构化编辑，Source 保留完整 YAML。GraphQL Query 和 Variables 使用可调整的上下编辑区。

代码面板采用无边框、无圆角的嵌入式编辑器，分隔线由外层工具栏和分栏提供。表格保留表头及行分隔，选择/删除列固定宽度，文本列可收缩。URL 与 Query 编辑双向同步；Body/Auth 模式切换保留各模式草稿。

响应区展示状态码、耗时、大小、正文、响应头、时间线和测试结果。JSON 正文可切换格式化/原始内容。SSE 显示增量 `data:`，WebSocket 显示消息时间线，支持回车发送、发送后清空和自动滚动。

## 变量展示和浮动补全

URL、参数、请求头以及使用共享变量输入组件的表单字段，在非编辑状态将完整 `{{name}}` 引用显示为 badge。悬停先显示当前启用的环境名称（未启用时显示“未选择环境”），再以 `变量名 = 值` 展示当前环境和请求作用域解析出的值。未定义显示“未设置”，空字符串与解析失败各有独立提示。点击后编辑原始文本，复制/保存不替换模板内容；遮蔽中的密码输入不展示 badge 预览。

输入 `{{` 后按前缀筛选候选变量，最多显示 8 项。候选面板绝对定位于输入框下方，通过浮层绘制，不参与表格行高计算；采用主题 popover 外观、左对齐条目、高度上限和滚动容器，并约束在窗口边界内。点击候选补全文本并保持输入焦点，完成引用或输入框失焦后不再显示候选。候选项悬停采用相同的环境与 `变量名 = 值` 提示。

HTTP JSON Body 和 GraphQL Variables JSON 编辑器为完整 `{{name}}` 引用添加主题强调色文字与浅色背景，未定义或无法解析的引用使用错误色；引号内外的模板均适用。悬停以小号弱色标题显示当前启用环境，下方加粗变量名并展示 `变量名 = 值`，不使用代码块边框或语言标签；变量值中的特殊字符与换行按原文展示。高亮和悬停不改写原始文本，也不改变焦点、选区或撤销历史；文本、环境或编辑模式变化会清除旧悬停内容。

预览复用核心静态变量解析，不运行前置脚本。环境变化会更新值，即使变量名称列表没有变化；值相同时也会更新环境名称。解析优先级和边界见 [执行规则](execution.md)。代码编辑器的脚本补全是另一套能力，不应与变量下拉面板混淆。

## 格式化、诊断和脚本补全

GraphQL、JSON、YAML、JavaScript 等编辑区提供格式化；非法语法不覆盖原文，格式化结果进入撤销历史，后台计算期间内容或语言改变则丢弃旧结果。

内置 LSP 在后台提供 JSON、JavaScript、GraphQL、YAML、XML、SPARQL 语法诊断，并检查 Markdown 中标明语言的代码围栏。诊断支持模板占位符、Unicode 位置和文档版本控制；不包含完整 JS 类型检查或 GraphQL schema 校验，也不会执行脚本。

Script/Tests 编辑器提供 API 和 JavaScript 内置成员补全，输入标识符或 `.` 可触发，Ctrl+Space 可手动唤起，方向键选择、Enter 插入、Esc 关闭。响应相关 API 只在后置和测试阶段提示。悬停展示参数和返回值说明。

## 设置与恢复

设置分为外观与语言、网络请求、代理、关于与更新。支持简体中文/English、浅色/深色/跟随系统、六种强调色和默认请求布局。设置输入跨分类和返回工作区后保留，保存后才应用；各分类底部固定显示“保存设置”按钮，也可用 Cmd/Ctrl+S 保存设置。Cmd/Ctrl+W 返回工作区，设置页发送快捷键不会发送隐藏请求。

语言切换更新应用文案和提示，不改写代码、服务端内容或请求草稿。应用设置跨项目使用，请求显式配置仍可覆盖相关网络默认值。关于页读取当前安装版本的发布介绍。

工作区输入草稿与已保存 YAML 分开保存；错误和未完成内容也可恢复。操作反馈通过统一的应用内右下角通知呈现；持久化失败会提示，关闭标签后重新打开仍保留草稿。具体位置见 [存储说明](storage.md)。

## 人工验收清单

以下是需要开发者手动确认的流程，不是已经通过的 GUI 测试。仓库禁止 Agent 使用 Computer Use、截图、键鼠模拟或辅助功能 API 验证；自动测试范围见 [开发与验证](development.md)。

1. **变量面板**：在 URL 和表格值中输入 `{{`，确认面板浮在输入框下方，勾选、说明、删除按钮及下一行不移动；靠近窗口边缘、滚动容器和窄窗口时仍可选择候选，补全后焦点保留。
2. **变量值**：用两个同名变量值不同的环境切换，确认 badge tooltip 更新；检查缺失、空字符串、嵌套引用和循环引用；点击编辑、复制和撤销仍保留模板文本。
3. **JSON 变量**：在 HTTP JSON Body 和 GraphQL Variables 中检查引号内外的完整模板、未完成模板、中文及 emoji 前缀、长值和缺失变量，确认明暗主题下的高亮及悬停环境、名称和值。编辑、选择、复制和撤销后原文与选区正确；切换环境（含值相同的环境）或 Body 模式后不残留旧悬停。
4. **导航与标签**：打开多层目录中的多个长名称文档，折叠目录后切换标签；检查定位、展开、横向滚动、拖拽和批量关闭。环境文档切换不改变请求的启用环境。
5. **编辑与恢复**：编辑 URL/Query、切换 Body/Auth 模式、保留无效 Source，关闭重开标签并重启；确认草稿恢复。另在磁盘修改已打开的 YAML，确认保存拒绝覆盖冲突。
6. **编辑器服务**：在不同语言中制造并修复语法错误，检查诊断与悬停；格式化后撤销，后台格式化时继续输入，快速切换语言和标签，确认无旧结果覆盖。
7. **请求与消息**：手动运行 `cargo demo`，依次发送健康检查、用户创建、上传、GraphQL、SSE 和 WebSocket；确认状态、断言、取消、消息时间线和回车发送。
8. **外观与设置**：在明暗主题、中英文、最小窗口和两种请求布局下检查表格、工具栏和分栏；保存设置后重启并切换项目，确认配置沿用。
9. **macOS 标题栏**：完全重启后检查原生窗口按钮与工具栏同排、空白区拖动/双击、全屏切换和菜单响应。

真实安装和更新验证另见 [更新与发布](auto-update.md)。
