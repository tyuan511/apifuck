# 工作区布局与交互

当前界面使用 GPUI Kit 原生组件，信息层级参考 Postman，API 工作流和部分数据互操作参考 Bruno。品牌资源使用 `assets/apifuck.png`，颜色与图标由应用主题统一管理。本页记录当前实现及待人工验收的行为，文件名保留以兼容已有链接。

## 导航和项目入口

- 顶部显示 logo、项目选择和启用环境；项目菜单包含“打开项目”“最近打开”“新建项目”“导入 .bru”。顶部项目选择仅显示名称和下拉箭头；“最近打开”带历史图标，最多记录 10 个去重路径。最近项目采用普通菜单行高的单行路径列表，不显示项目名称、条目图标或勾选；用户主目录缩写为 `~`，其他位置保留原路径。菜单随内容调整宽度（240–480px），超长路径省略，不弹出重复路径提示。子菜单底部分隔线下提供“清除”，点击后清空并保存最近项目记录，保留当前项目和文件；空列表时该操作禁用，保存失败时保留原记录并提示错误。
- 启动和打开项目时静默读取，不显示读取中的通知；读取失败仍显示错误提示。
- 集合级配置通过集合标题旁的设置按钮打开。项目菜单没有“项目设置”或“删除项目”。左侧“设置”负责应用偏好。
- 左侧功能栏仅显示图标，切换集合、环境和设置；悬停时在右侧显示当前语言的完整菜单名。更新入口同样仅显示图标，提示中保留更新状态。集合与环境各有独立搜索，新建/刷新按钮在各自标题行。
- 集合树使用固定方法列、可展开的文件夹、长名称省略和悬停说明；同级请求和目录支持拖拽排序。滚动条沿侧栏右边缘显示，列表行保留左右留白。目录不显示额外展开箭头，点击文件夹图标、名称或行内空白均切换展开/收起，文件夹图标同步显示开合状态；右键“编辑”或选中后按 Enter/Space 打开目录配置。
- 文件夹和接口右键提供编辑、重命名、创建副本、移动或重命名文件、重新载入、复制为 `.bru`、移到废纸篓；接口的复制选项统一收在“复制为”二级菜单中：HTTP/GraphQL 提供 cURL、JavaScript、Python、Go 和 `.bru`，WebSocket 提供 `.bru`。重命名聚焦文档名称输入框，保存后只修改显示名称；文件移动使用独立路径操作。
- 文件夹右键可在该目录内新建 HTTP、GraphQL、WebSocket 接口或子目录，即使当前标签属于其他目录。菜单操作始终针对右键节点；文件夹副本包含子目录、接口和普通资源文件。移动会迁移已打开及已关闭接口的本机草稿；回收需确认，运行中的请求须先停止再移动或回收。
- 环境列表区分“正在编辑”和“当前启用”。点击列表项只打开环境文档，启用环境由顶部选择器控制。
- 集合树的请求、目录配置和环境列表在条目最右侧显示未保存小点，与标签栏样式一致。关闭标签或重启后保留草稿标记，保存或放弃修改后清除；仅有布局、WebSocket 待发送内容等界面状态不显示小点。

## 文档和标签

新建 HTTP、GraphQL、WebSocket 请求直接创建唯一文件并打开标签，名称输入自动聚焦；无需输入路径。URL 默认为空，HTTP 默认 GET，GraphQL 默认 POST。目录与环境输入显示名称后创建，实际文件路径由应用生成。名称与文件身份规则见 [存储说明](storage.md)。

文档标签支持拖动排序、横向滚动、长标题省略、完整标题列表，以及右键关闭当前/其他/左侧/右侧/全部。关闭后台标签保持当前请求，关闭当前标签选择相邻项。批量关闭同样保留草稿。

没有打开的文档时，右侧只显示居中的空态提示，不显示顶部标签栏、标签列表下拉及“生成代码”“更多”操作；打开文档后恢复标签栏。

切换标签、关闭后选择相邻标签和启动恢复都会同步侧栏：请求/目录定位集合树并展开父级，环境文档定位环境列表但不改变启用环境。若搜索隐藏目标，只清除对应侧栏的搜索条件。

## 请求与响应

默认请求在上、响应在下，可切换左右布局并调整分栏。顶部方法/URL 组合输入框与发送、保存操作保持在请求区上方；运行期间发送按钮切换为停止。

请求名称行右侧提供“生成代码”“更多”和带图标的“切换布局”按钮；布局按钮在上下与左右排列之间切换，仅影响当前请求。每个请求的选择保存在本机工作区，重新打开或重启后恢复；未单独切换的请求跟随应用默认布局，修改默认布局不会覆盖已有的单请求选择。

请求按用途提供 Query/Path、Body、Headers、Auth、Vars、Script、Assert、Tests、Docs、Settings 和 Source 等分区。表单负责结构化编辑，Source 保留完整 YAML。GraphQL Query 和 Variables 使用可调整的上下编辑区。

“请求头”在收到发送结果后默认展示只读的“实际发送”视图，列出本次请求的方法、URL 和全部目标请求头，包括继承、认证、脚本及自动生成的字段；“编辑配置”可切回原有表格。发生重定向时默认展示最后一次请求，可通过序号菜单查看各次请求；WebSocket 展示握手头。记录支持复制，只在当前标签内存中保留，不写入 YAML 或本机草稿；再次发送会清空旧记录。未收到响应头时不会生成已发送记录，收到响应头后即使读取正文失败或取消，仍保留对应记录。

代码面板采用无边框、无圆角的嵌入式编辑器，分隔线由外层工具栏和分栏提供。表格保留表头及行分隔，选择/删除列固定宽度，文本列可收缩。URL 与 Query 编辑双向同步；Body/Auth 模式切换保留各模式草稿。

多部分表单中，文件类型的值栏提供“选择文件…”按钮，打开系统单文件选择器；选择后更新当前行的路径，取消保留原值。路径仍可手动编辑，以支持相对路径和变量；切换字段类型只改变类型，不自动弹出文件选择器。

响应区展示状态码、耗时、大小、正文、响应头、时间线和测试结果。JSON 正文可切换格式化/原始内容。SSE 显示增量 `data:`，WebSocket 显示消息时间线，支持回车发送、发送后清空和自动滚动。

## 变量展示和浮动补全

URL、参数、请求头以及使用共享变量输入组件的表单字段，在非编辑状态将完整 `{{name}}` 引用显示为 badge。悬停先显示当前启用的环境名称（未启用时显示“未选择环境”），再以 `变量名 = 值` 展示当前环境和请求作用域解析出的值。未定义显示“未设置”，空字符串与解析失败各有独立提示。点击后编辑原始文本，复制/保存不替换模板内容；遮蔽中的密码输入不展示 badge 预览。

输入 `{{` 后按前缀筛选候选变量，最多显示 8 项。候选面板绝对定位于输入框下方，通过浮层绘制，不参与表格行高计算；采用主题 popover 外观、左对齐条目、高度上限和滚动容器，并约束在窗口边界内。点击候选补全文本并保持输入焦点，完成引用或输入框失焦后不再显示候选。候选项悬停采用相同的环境与 `变量名 = 值` 提示。

HTTP JSON Body 和 GraphQL Variables JSON 编辑器为完整 `{{name}}` 引用添加主题强调色文字与浅色背景，未定义或无法解析的引用使用错误色；引号内外的模板均适用。悬停以小号弱色标题显示当前启用环境，下方加粗变量名并展示 `变量名 = 值`，不使用代码块边框或语言标签；变量值中的特殊字符与换行按原文展示。高亮和悬停不改写原始文本，也不改变焦点、选区或撤销历史；文本、环境或编辑模式变化会清除旧悬停内容。

预览复用核心静态变量解析，不运行前置脚本。环境变化会更新值，即使变量名称列表没有变化；值相同时也会更新环境名称。解析优先级和边界见 [执行规则](execution.md)。代码编辑器的脚本补全是另一套能力，不应与变量下拉面板混淆。

## 格式化、诊断和脚本补全

GraphQL、JSON、YAML、JavaScript 等编辑区提供格式化；非法语法不覆盖原文，格式化结果进入撤销历史，后台计算期间内容或语言改变则丢弃旧结果。JSON 请求正文、GraphQL Variables 和响应正文统一使用每层 2 个空格缩进，非空对象和数组始终展开换行，空对象和空数组保持 `{}` / `[]`；保留字段顺序、重复字段、数字精度和变量模板，响应的“原始内容”仍显示服务器原文。

内置 LSP 在后台提供 JSON、JavaScript、GraphQL、YAML、XML、SPARQL 语法诊断，并检查 Markdown 中标明语言的代码围栏。诊断支持模板占位符、Unicode 位置和文档版本控制；不包含完整 JS 类型检查或 GraphQL schema 校验，也不会执行脚本。

Script/Tests 编辑器提供 API 和 JavaScript 内置成员补全，输入标识符或 `.` 可触发，Ctrl+Space 可手动唤起，方向键选择、Enter 插入、Esc 关闭。响应相关 API 只在后置和测试阶段提示。悬停展示参数和返回值说明。

## 设置与恢复

设置分为外观与语言、网络请求、代理、关于与更新。支持简体中文/English、浅色/深色/跟随系统、六种强调色和默认请求布局。设置输入跨分类和返回工作区后保留，保存后才应用；各分类底部固定显示“保存设置”按钮，也可用 Cmd/Ctrl+S 保存设置。Cmd/Ctrl+W 返回工作区，设置页发送快捷键不会发送隐藏请求。

语言切换更新应用文案和提示，不改写代码、服务端内容或请求草稿。应用设置跨项目使用，请求显式配置仍可覆盖相关网络默认值。关于页读取当前安装版本的发布介绍。

代理分类使用「代理方式」下拉框，提供「无代理」「使用系统代理」和「自定义代理」三项。无代理模式直接连接，禁用系统和环境变量代理；系统代理模式自动读取代理配置。这两种模式均无需填写地址；仅选择自定义代理时显示地址输入框，保存时要求填写完整且有效的 HTTP、HTTPS、SOCKS5 或 SOCKS5H 地址。切换选项保留地址草稿，无代理和系统模式不校验或使用隐藏的地址；已有非空代理地址自动对应自定义模式。代理模式和未完成地址随设置草稿恢复，保存后才生效。系统模式沿用 HTTP 客户端的环境变量和操作系统代理发现（macOS/Windows）；集合中显式配置的代理仍优先，WebSocket 的代理限制不变。

工作区输入草稿与已保存 YAML 分开保存；错误和未完成内容也可恢复。操作反馈通过统一的应用内右下角通知呈现；持久化失败会提示，关闭标签后重新打开仍保留草稿。具体位置见 [存储说明](storage.md)。

请求头、响应内容、生成代码及 Bru 源码复制后显示对应的成功通知。“生成代码”或右键“复制为”选择语言后直接生成并复制该语言的代码，不打开预览弹窗；生成失败时显示错误通知，保留原剪贴板内容。格式化完成会提示；内容无需修改时提示“内容已是标准格式”，失败或内容已变化时保留原文并说明原因。

## 人工验收清单

- **代理设置**：使用代理方式下拉框切换无代理/系统/自定义代理，确认只有自定义模式在下方显示地址输入框，往返切换保留输入；自定义地址为空或无效时保存应报错，切回无代理或系统模式可保存。系统配置代理时选择无代理，确认请求直接连接。返回工作区、重新进入设置并重启，确认模式与地址草稿恢复；在中英文和明暗主题下检查选中状态及布局。原生交互仍需人工验收。

- 点击请求头、响应内容的复制以及“生成代码”或右键“复制为”中的语言选项，确认右下角出现对应通知，代码复制不打开预览弹窗，粘贴内容与所选内容一致；生成失败时确认只有错误提示且原剪贴板内容不变；切换中英文后重复检查。格式化可调整和已格式化的内容，分别确认完成与无需修改的提示；原生通知的可见性需人工验收。

以下是需要开发者手动确认的流程，不是已经通过的 GUI 测试。仓库禁止 Agent 使用 Computer Use、截图、键鼠模拟或辅助功能 API 验证；自动测试范围见 [开发与验证](development.md)。

1. **变量面板**：在 URL 和表格值中输入 `{{`，确认面板浮在输入框下方，勾选、说明、删除按钮及下一行不移动；靠近窗口边缘、滚动容器和窄窗口时仍可选择候选，补全后焦点保留。
2. **变量值**：用两个同名变量值不同的环境切换，确认 badge tooltip 更新；检查缺失、空字符串、嵌套引用和循环引用；点击编辑、复制和撤销仍保留模板文本。
3. **JSON 变量**：在 HTTP JSON Body 和 GraphQL Variables 中检查引号内外的完整模板、未完成模板、中文及 emoji 前缀、长值和缺失变量，确认明暗主题下的高亮及悬停环境、名称和值。编辑、选择、复制和撤销后原文与选区正确；切换环境（含值相同的环境）或 Body 模式后不残留旧悬停。
4. **导航与标签**：展开足够多的集合条目并滚动，确认滚动条靠侧栏右边缘，列表行留白不变；调整侧栏宽度后仍贴边，拖动滚动条可到达列表顶部和底部。确认目录前无额外展开箭头，点击文件夹图标、名称和行内空白均只切换一次展开/收起，且不打开配置标签；空目录也可切换图标状态，右键“编辑”可打开目录配置。打开多层目录中的多个长名称文档，折叠目录后切换标签；检查定位、展开、横向滚动、拖拽和批量关闭。环境文档切换不改变请求的启用环境。
5. **编辑与恢复**：编辑 URL/Query、切换 Body/Auth 模式、保留无效 Source，关闭重开标签并重启；确认草稿恢复。检查请求、目录配置和环境的未保存小点位于侧栏行最右侧，长名称和窄侧栏不会挤掉小点；关闭标签后标记保留，保存或放弃修改后消失，搜索与切换侧栏后仍正确显示。另在磁盘修改已打开的 YAML，确认保存拒绝覆盖冲突。
6. **编辑器服务**：在不同语言中制造并修复语法错误，检查诊断与悬停；格式化后撤销，后台格式化时继续输入，快速切换语言和标签，确认无旧结果覆盖。
7. **请求与消息**：手动运行 `cargo demo`，依次发送健康检查、用户创建、上传、GraphQL、SSE 和 WebSocket；确认状态、断言、取消、消息时间线和回车发送。
8. **外观与设置**：在明暗主题、中英文、最小窗口和两种请求布局下检查表格、工具栏和分栏；确认左侧功能栏仅显示图标，悬停时右侧完整显示菜单名，更新入口的提示保留更新状态，点击和选中状态正常；保存设置后重启并切换项目，确认配置沿用。
9. **macOS 标题栏**：完全重启后检查原生窗口按钮与工具栏同排、空白区拖动/双击、全屏切换和菜单响应。
10. **表单文件选择**：打开已有 multipart 请求，确认只有文件行的值栏显示“选择文件…”；选择或更换文件后路径更新，取消保留原值，文本/文件切换保留值。检查长路径、窄窗口、中英文，以及保存、重开草稿后发送上传请求。
11. **请求操作与布局**：确认“生成代码”“更多”和布局图标位于请求名称行右侧，长名称和窄窗口下按钮仍可用；打开两个请求，只切换其中一个的布局，确认另一个不变，重开或重启后保留。修改应用默认布局，确认仅未单独选择布局的请求跟随变化；HTTP、GraphQL、WebSocket 均可切换布局，代码生成仍仅对支持的请求开放。

12. **项目菜单**：确认顶部项目名前没有图标，“最近打开”前显示历史图标；检查空列表、多项目、同名项目和长路径，确认条目仅显示单行路径，用户主目录缩写为 `~`，其他路径保持原样；没有文件夹图标、勾选或重复悬浮提示，超长路径不越界。用鼠标和键盘打开最近项目，检查明暗主题和窄窗口下子菜单仍可操作。点击底部“清除”后重新打开子菜单，确认显示“暂无最近项目”且“清除”禁用，当前项目及编辑状态保留；重启后不恢复已清除的历史，再次打开项目可重新记录。

13. **实际请求头**：配置继承头、认证、模板变量和前置脚本后发送，在“请求头 → 实际发送”确认展开值和自动头，可复制、查看重定向的不同请求；切回“编辑配置”确认原始模板、禁用行和编辑内容仍在。再次发送失败时不残留上次记录；流式响应取消后仍可查看本次已收到响应的请求头。

真实安装和更新验证另见 [更新与发布](auto-update.md)。

右键菜单补充人工验收：保持接口 A 为当前标签，右键其他文件夹 B 新建三种接口和子目录，确认均落在 B；右键接口 C 重命名、创建副本、移动、导出或回收，确认目标始终为 C。对带嵌套接口的文件夹重复操作，检查子树、目录配置、名称聚焦和搜索后的定位；确认取消回收无文件变化。将含已关闭无效草稿的目录移动后重新打开接口，确认草稿仍在。以上交互与视觉验收尚需人工完成，自动化测试不代替原生 UI 验收。

## MCP 原生设置人工验收

自动测试不启动桌面窗口，也不能证明原生界面视觉和四个 Agent 的实际连接。需要人工确认：

1. 运行本次构建的 `apifuck-desktop`，侧栏打开「设置」，确认有 MCP 分类；切换中英文检查文案。
2. 开启 MCP，确认运行状态与地址；关闭后连接应中断，重新开启后可刷新 Agent 连接。退出重启应恢复已保存的开关状态。
3. 分别选择 Claude Code、Codex、OpenCode、Pi，复制配置并按教程合并，验证 `get_workspace` 返回当前原生项目。
4. 通过 Agent 修改一个已保存的请求，确认集合树和干净标签更新；保留未保存草稿后再次尝试修改，确认操作被拒绝且草稿保留。
5. 使用另一程序占用配置端口时启动服务，确认失败状态与重试提示；解除占用后可恢复。
